## Layout

- `frontend/` is the whole app (Next.js 16, React 19, Tailwind v4, dnd-kit). The root `main.py`/`pyproject.toml` are unused course scaffolding.
- `frontend/AGENTS.md` is generated by `next dev`: this Next.js version has breaking changes, so read the relevant guide in `frontend/node_modules/next/dist/docs/` before writing Next.js code.

## Commands

Run from `frontend/` (Node 22.12+):

```bash
npm run dev                              # http://localhost:3000
npm run build
npm run lint
npm test                                 # Vitest unit tests (src/**/*.test.{ts,tsx})
npx vitest run src/lib/board.test.ts     # single test file
npx vitest run -t "renames and trims"      # single test by name
npm run test:e2e                         # Playwright (e2e/), starts or reuses dev server on :3000
npx playwright test -g "renames a column" # single e2e test by name
```

## Architecture

- All state is in-memory in `Board.tsx` via `useReducer(boardReducer, initialBoard)`; no persistence. `initialBoard` in `src/lib/initialData.ts` is the dummy data.
- `src/lib/board.ts` holds the normalized state shape (`columns[].cardIds` + `cards` map) and a pure reducer with four actions: `renameColumn`, `addCard`, `deleteCard`, `moveCard`. Put state logic here and unit-test it in `board.test.ts`.
- Drag and drop: a single `DndContext` in `Board.tsx`. Each `Column` is a droppable (id = column id) wrapping a `SortableContext`; each `Card` is sortable (id = card id). `findColumnId` resolves either id type to a column. `onDragOver` moves cards across columns live; `onDragEnd` handles the final reorder within a column. A `DragOverlay` renders `CardView` while dragging.
- Colors are Tailwind theme tokens in `src/app/globals.css` (`accent`, `primary`, `secondary`, `navy`, `muted`), e.g. `bg-accent`, `text-navy`. Use these rather than raw hex values.
- E2E tests locate columns by `getByRole("region", { name })` (the column `<section aria-label>`), drag with real mouse moves (pointer sensor needs 5px activation distance), and fail on any console error.
